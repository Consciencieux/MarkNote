# 隐私说明

本文说明当前代码中的数据处理方式，供开发和发布准备使用，不替代发行者面向用户发布的隐私政策。

## 应用处理的数据

MarkNote 通过 HarmonyOS 文件选择器或文件管理器授权访问用户文稿。应用私有空间保存最近文稿的 URI 和文件名、未保存草稿和外观偏好。最近文稿和偏好使用本机 Preferences，草稿保存在应用私有目录的 `unsaved-draft.json`。旧版本保存的工具栏位置偏好不再使用。

应用不申请 `ohos.permission.INTERNET`，未接入账号、广告、分析 SDK 或云同步。预览资源随应用打包，预览页面不加载外部图片或脚本，也不发起网络连接。“关于”页的 GitHub 入口由系统浏览器打开，网页访问由浏览器处理。

用户在系统设置中清除应用数据时，应用保存的草稿、最近文稿记录和偏好会被删除。通过文件选择器保存在外部位置的文件不属于这些应用数据。

## 发布前核对

发行者应根据最终应用的数据处理方式编写并发布隐私政策，补充运营主体、联系方式、生效日期和公开网址，并核对应用市场中的权限、SDK 与数据声明。
