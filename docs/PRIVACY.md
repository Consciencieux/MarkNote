# 隐私说明（应用市场发布文案基础）

## 当前实现

Marknote 在本机编辑 Markdown、纯文本、SVG 和 TeX 数学表达式文稿。用户通过 HarmonyOS
系统文件选择器或文件管理器的打开授权访问文稿。最近文稿的 URI 与未保存草稿保存在应用私有空间；
选择系统设置项保存在本机 Preferences 中。

应用不需要 `ohos.permission.INTERNET`，不接入账号、广告、分析 SDK、云同步或远程字体/CDN。
文稿预览中的外部图片、脚本和网络连接被禁用。第三方代码/数学字体已打包在本地。

用户可在系统设置中清除本应用数据；此操作会删除应用内草稿、历史与偏好，
但不会删除用户通过系统文件选择器保存到外部位置的原始文件。

## 上架信息

此文件需要由实际发行者填写运营主体、联系方式、生效日期以及公开的隐私政策 URL，
并与最终 HAP 的权限、SDK 和数据行为一致。不能直接使用本文件代替应用市场的
线上隐私政策链接。
