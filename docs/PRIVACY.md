# 隐私说明

本页记录 MarkNote 当前的数据行为，以及面向应用市场发布时需要由发行者补齐的字段。

## 当前数据行为

MarkNote 在本机编辑 Markdown、纯文本、SVG 和 TeX 数学表达式文稿。文稿通过 HarmonyOS 系统文件选择器或文件管理器的打开授权访问。

应用私有空间保存三类数据：最近文稿的 URI 与文件名、未保存草稿、外观偏好。最近文稿和外观偏好存放在本机 Preferences（`marknote-settings`）中，草稿存放在应用私有目录的 `unsaved-draft.json`。

应用不申请 `ohos.permission.INTERNET`，不接入账号、广告、分析 SDK 和云同步，也不从远程加载字体或脚本。预览中的外部图片、脚本和网络连接均被禁止，第三方代码和数学字体打包在本地。

用户在系统设置中清除本应用数据后，草稿、最近文稿记录和外观偏好会被删除；通过系统文件选择器保存到外部位置的原始文件不受影响。

## 发布前需要补齐

本文件不能替代线上隐私政策。发行者需要填写运营主体、联系方式、生效日期和公开的隐私政策 URL，并确保内容与最终 HAP 的权限、SDK 和数据行为保持一致。
