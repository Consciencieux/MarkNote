# 上架准备

本文记录发布前需要核对的项目。应用市场的要求可能变化，发行者应以提交时的平台要求为准。

## 产品文案

- 应用名称：MarkNote。
- 一句话简介：支持多种格式的文本编辑与预览。
- 详细介绍：MarkNote 是一款面向本地文稿的轻量编辑应用，方便在移动设备上阅读和修改常用文稿。支持 Markdown、纯文本、SVG 和常见 LaTeX 文件，支持直接打开、修改、保存和分享本地文件。Markdown 和 LaTeX 文稿支持大纲浏览与章节跳转。应用采用鸿蒙原生组件，界面简洁清晰，在保持轻量的同时提供顺手的阅读与编辑体验。

## 发布前检查

1. 按[构建与贡献](../CONTRIBUTING.md)中的步骤检查并构建预览和应用。
2. 在应用中检查“隐私说明”、本项目许可证和第三方许可证。核对实际分发依赖、NOTICE 和字体授权。
3. 在目标设备上验证安装、文件打开与保存、文件管理器关联、只读文件另存为、外部修改检查、草稿恢复、外观切换及离线预览。记录实际覆盖的设备与系统版本。
4. 核对 `module.json5` 中的文件关联与市场声明，并确认应用实际支持的打开方式。
5. 使用发行者有权使用的包名、签名材料、商标和商店素材。包名以 `AppScope/app.json5` 为准；需要更改时，应先确认迁移及发行影响。
6. 根据[隐私说明](PRIVACY.md)核对最终数据行为，准备并发布隐私政策，使政策、应用及市场声明一致。
7. 核对应用市场当前要求的开发者资质、备案、隐私安全、内容分级及截图等材料。

GitHub Release 的未签名 debug HAP 不是应用市场分发包。

功能的具体行为和限制见[功能目录](FEATURES.md)。
